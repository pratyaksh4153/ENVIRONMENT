# 🌿 EcoLife – Environmental Awareness Website

EcoLife is a responsive website that promotes environmental protection, waste management, recycling, and sustainable living.

## Features
- 🌱 Environmental awareness
- ♻️ Waste management tips
- 💧 Eco-friendly habits
- ✅ Interactive action checklist
- 🧠 Eco Quiz

## Technologies
- HTML
- CSS
- JavaScript

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Interactive features

## How to Run
Open `index.html` in your browser or use VS Code Live Server.

**Goal:** Small steps, big impact! 🌍
